Kubo

A personal desktop launcher for Minecraft Java Edition, built for private, non-commercial use.

What it does

  • Signs the player in with their Microsoft account (OAuth) and verifies game ownership through the official Xbox Live and Minecraft Services flow.
  • Downloads and launches official game versions, with optional Fabric support.
  • Installs mods from Modrinth into a local game folder.

Licensing and security

A purchased Minecraft Java Edition license is required to play. Kubo does not bypass, disable or weaken any authentication, licensing or security checks, and it does not provide offline or cracked account modes.

Privacy

Account tokens are stored only on the user's own computer. Kubo has no servers, does not collect analytics and does not send personal data to anyone other than Microsoft, Xbox Live and Mojang for sign-in.
